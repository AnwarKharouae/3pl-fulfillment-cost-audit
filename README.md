# 3pl-fulfillment-cost-audit
## 📁 Dataset & Data Access

Due to GitHub file size limits (>50 MB), the complete 60 MB raw dataset is hosted externally on Kaggle.

* **Full Dataset:** Download the complete 3-month operational dataset on [Kaggle](https://www.kaggle.com/datasets/thedevastator/unlock-profits-with-e-commerce-sales-data).
**Primary Source File:** The core audit relies specifically on the `Amazon Sales Report.csv` and `Cloud Warehouse Compersion Chart.csv`  file within the dataset, covering April – June 2022 order lines, KPI and operating costs.
